# 分批实施计划

给实现者（含 Claude Code）的任务清单。共 6 批，按顺序做（第 6 批 iPhone Duo 的外壳部分可以提前），一批一个可独立构建、可回退的改动。每批结束都要能编译、通过静态检查和相关测试，且 App 功能不缺失。

## 通用规则

- 开始前按 `AGENTS.md` 的 Start 流程；涉及阅读器、导入、远程、缓存、导航时先读 `docs/maintenance-pitfalls.md` 对应章节。
- 只做当前批次。不提前做后面的批次，不顺手重构无关代码，不新增依赖。
- 视觉对照组件与页面卡片：浏览器打开 `docs/design-system/index.html`。数值以 `tokens.json` 为准，组件规则以各组件 `README.md` 为准。
- 设计与现有能力不符（功能不存在、数据拿不到、API 在 iOS 17.6 不可用）时：保留现有行为，在汇报中列出，不自行发明行为。
- **受保护组件**：`ReaderBottomBar`、`ReaderThumbnailScrubber`（含浮动预览与页码胶囊）、`ReaderVerticalThumbnailRail` 的外观、布局、动效、显隐、触控、跳页行为一律不改，也不能被共享 token 改动间接影响。
- 页面左右边距用系统容器边距（UIKit 布局边距 / compositional layout `contentInsetsReference = .layoutMargins`；SwiftUI `List`、`Form` 自带，自定义内容 iOS 27.1 起用 `.contentMargins(for: .container)`），不新写死 `.padding(.horizontal, 16)`。见 `00-foundations.md`“间距与布局”与 `06-iphone-duo.md`“页面边距”。
- 系统控件优先：`UITabBarController` / split view、`Menu` / `contextMenu`、`Form`、`.searchable`、`confirmationDialog`。iOS 26 的 Liquid Glass 交给系统，不自绘玻璃。
- 所有新增或修改的文案同时覆盖 en、zh-Hans、zh-Hant、ja，并通过 `scripts/check_localizations.py`。用词按“视觉与文案基础”的固定用词表（`00-foundations.md`）。
- 删除 / 移除 / 清理的文案与确认弹窗按 `02-architecture.md` 的后果表；破坏性操作必须确认。
- 每批结束：静态检查、`git diff --check`、构建、相关 XCTest，再逐条对照本批“验收”。行为或入口变化时，同步更新拥有它的文档（`docs/README.md` 的分工表）。不提交、不推送，除非被要求。

- 验收后修正（2026-10-28）：写死的系统色按 token 替换——书库根目录集合入口（收藏 `favorite`、最近加入 / 继续阅读 `accent`、标签 `offline`、阅读列表 `success`）、书库类型色块（App 内 `jam`、关联文件夹 `offline`、已导入灰，`LibraryKindStyle.swift`）、侧滑按钮、远程首页与服务器详情的入口图标、协议图标改 `accent`；远程无封面占位改 `surface-2` 底 + `ink-3` 书本，文件夹图标 `accent`，其它文件中性色；设置页图标色块与标签数据色保留。远程标题前的绿色小图标只是“可作为漫画打开”的类型标记（文件夹蓝、漫画绿、其它灰），不表达状态，已从列表与网格删除；同时修正复用单元格把文件夹占位图留给漫画的问题。继续阅读卡片的次要文字改为显式 `ink-2`（原为继承按钮色的层级色，显出浅粉）。导入去处选中态改为 `accent` 边框 + `accent-soft` 底。`StatusBadge` 在辅助功能字号下逐词排版（`WrappingHStack`），只在词之间换行，放不下时整枚徽标换行；中日文按字换行，单个超长英文词缩小而不拆开。漫画信息页的阅读进度改为普通副标题文字，辅助功能字号下封面与文字改为上下排列。截图在 `.acceptance/batch-1-fix/`。

**目标**：外屏用现有 iPhone 布局、内屏用现有 iPad 布局，按窗口宽度切换；开合连续；只做系统要求的避让。规则见 `06-iphone-duo.md`。

**对照**：`ScreenDuoLibrary`、`ScreenDuoReader`、`ProtectedNavigation`、`ScreenIPad`。

**顺序**：外壳与列表部分可以随时做；阅读器部分在第 4 批之后做（第 4 批会改顶栏与显示面板）。

- [x] **先保护**：改动前在 iPhone 与 iPad 各截一组底部导航列表、右侧轨道、页码胶囊、浮动预览的图（分页 / 竖向、工具显示），作为逐像素对照。

- 浮动元素与圆角：`TaskBanner`、`LightToast`、远程目录底部任务卡、全局导入浮层加 `staysClearOfActiveVerticalFold()`：竖向折叠区启用时放到后缘一侧。`TaskBanner` 背景在 iOS 27.1 起用 `ConcentricRectangle`（最小圆角仍为 `radius-xl`）。没有找到用于布局的设备方向判断；iPhone 支持横屏，未锁竖屏。
- Sheet：“添加漫画”Sheet 只有“取消”和一列大行，设 `toolbarVerticalBehavior(.disabled)` 保持水平栏；表单类 Sheet 不改。**未完成 Device Hub 对比**（见下），所以该项没有勾选。
- 为了让 iPhone / iPad（模拟器为 iOS 27.0）截图与改动前一致，凡是会改变水平栏外观的新行为（溢出菜单、选择 / 完成符号、同心圆角、容器边距）都只在 iOS 27.1 起启用；iOS 27.1 的普通 iPhone 也会采用这些行为，这与 `06-iphone-duo.md`“iOS 27 起”的方向一致。
- 测试：新增 `AdaptiveSplitShellTests`（折叠 / 展开移交同一批页面、占位页不移、无页面时请求恢复、重复通知不重复移动）、`FoldSplitGridMetricsTests`（偶数列与中缝、偏心折痕、开合不重排、无折叠区）、侧栏选中项存取测试；删除已不存在 API 的旧测试。
