# 阅读器

## 原样保留（不在设计范围）

- **分页阅读底部缩略图导航列表**：`ReaderBottomBar`（`ReaderThumbnailScrubber`、条目放大与抬升、浮动页面预览、下方页码胶囊）。
- **竖向连续阅读右侧缩略图导航列表**：`ReaderVerticalThumbnailRail`（轨道、拖动预览、松手跳页、紧凑页码入口）。

位置、尺寸、间距、缩略图样式、动效、显隐、触控、跳页行为全部不改。实现改版时，这两个组件**不要**改为引用新的共享 token：把它们现在依赖的 `Spacing`、`AppFont`、材质值冻结为组件私有常量，确保共享 token 变化不会间接改变它们。周边工具的出现与动画不得移动或挤压它们。

## 可以重设计的部分

| 部分 | 新方案 | 组件 |
| --- | --- | --- |
| 顶栏 | 返回 · 书名（纯文字 + 随工具淡入淡出的渐变遮罩）· [书签 · Aa · ⋯] 三键胶囊；不显示页码 | `ReaderTopBar` |
| 显示设置 | `Aa` 打开浮动面板（iPhone 底部 / iPad popover），所见即所得 | `ReaderDisplayPanel` |

| 页码与跳页 | 不新增入口：页码只显示在底部页码胶囊，点它打开现有跳页浮层 | 受保护组件 |
| 跨本导航胶囊 | 位置与行为不变，换统一材质 | `ReaderTopBar` |
| 准备阅读 / 打不开 | 黑底保留封面，写明原因与进度；左上 × 取消；失败给重试与编辑服务器 | `ScreenRemoteActions` |

## 行为契约（任何方案都不能改）

- 分页：横向滑动、边缘点按翻页、中央点按显隐工具；不重新划分触控区，不改响应时机。
- 竖向：上下连续滚动、整页宽度、画布缩放与平移；不套用分页点按规则。工具隐藏且有本地序列时，边缘点按打开上一 / 下一本；工具显示时边缘点按收起工具。
- 退出：分页向下滑、竖向向右滑、显式返回按钮；缩放与平移优先。
- 工具显隐不挤压画面、不改变漫画尺寸；避开安全区；旋转与 iPad 窗口变化后仍定位当前页。
- 精确找页：输入页码（非法时清楚提示）、缩略图总览、定位当前页、书签与跳转。
- 跨本阅读：保留本地序列上一 / 下一本与边缘行为，不改成自动翻到下一本，不扩展到远程。
- 布局选项保存为共享默认值；旋转只作用于当前阅读。不设计“每本单独记忆”。
- 标为已读 / 未读会调整阅读位置，菜单副标题需提示。
- 本地书签每本最多 3 个；远程无此上限。
- 能力随格式：PDF / EPUB 渲染为固定单页，不显示布局、方向、双页与旋转；EPUB 网页模式可能没有页码与书签。不给无效控件。

## iPhone Duo

外屏按紧凑宽度（同 iPhone）、内屏按常规宽度（同 iPad）显示阅读器。单双页沿用用户偏好，内屏横放不自动切双页；外屏暂时显示单页但不改写偏好。双页的跨页中心对准折痕，半折时两页分居两侧。两个受保护导航列表**只做环境适配**：档位按窗口（iPad 或常规宽度窗口用 iPad 档），容器避开侧边状态栏 / 灵动岛与折叠区，外观与行为不变。完整规则见 `06-iphone-duo.md`，对照 `ScreenDuoReader`。

现状（2026-10-30）：阅读器的尺寸都取自窗口与容器（不再回退到屏幕尺寸），`Aa` 按尺寸类别选面板形式，缩略图总览按窗口宽度类别与容器宽度定列数；外屏单页显示不改写双页偏好。折痕相关的几何（跨页对准折痕、半折分区、外屏摄像头保留区、导航列表的档位与半折限制）尚未实现，见 `05-batches.md` 第 6 批（下）实施说明。
