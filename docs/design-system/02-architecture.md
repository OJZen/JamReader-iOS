# 信息架构与流程

总览图见页面卡片 `InformationArchitecture`。三个一级分区不变，名称与内部层级调整。

## 一级导航

| iPhone 标签 | iPad | 内容 |
| --- | --- | --- |
| 书库 `books.vertical` | 侧栏：继续阅读 · 我的书库 · 当前书库的集合 | 本地书库、导入、整理 |
| 远程 `server.rack`（原“浏览”） | 侧栏：离线书架 · 已保存文件夹 · 服务器 | SMB / WebDAV、离线副本 |
| 设置 `gearshape` | 侧栏：通用 · 阅读 · 书库 · 存储 | 全局默认值与存储管理 |

阅读器是全屏呈现，从任何封面进入，退出回到原位置与原分组。

## 入口合并：之前 → 之后

| 功能 | 之前 | 之后 |
| --- | --- | --- |
| 添加 | [+] 菜单 4 个术语项；空态另有“新建书库” | [+] 与空态按钮二选一，打开同一个“添加漫画”Sheet |
| 书库内导入文件 | Library 菜单 “Import Comic Files” | 根目录与子文件夹相同：⋯ 第一项“导入到这里…”；空文件夹的空态按钮也是它 |
| 导入漫画资料（ComicInfo） | “导入”与“刷新与扫描”两组共 3 个入口 | ⋯ →“导入漫画资料…”：先选范围（所选 / 当前列表 / 当前文件夹及子文件夹 / 整个书库），再选补空白或覆盖；多选时直接用所选范围 |
| 刷新与扫描 | 子菜单两项 | ⋯ →“刷新与扫描”（当前文件夹 / 整个书库），进度进 TaskBanner |
| 最近加入时限 | 书库内容页 View 菜单 + 设置 | 只在设置 → 书库 与“最近加入”页 |
| 排序 / 显示方式 | View 菜单、列表头、按钮混用 | 排序在“漫画”分区标题右侧；网格 / 列表在 ⋯ |
| 继续阅读 | 每个书库根目录 | 二选一：书库首页（汇总，默认）或各书库内；书库内另有筛选“阅读中” |
| 层级返回 | 系统返回 + “Up / Library”按钮 | 系统返回 + 大标题下的可点面包屑 |
| 维护状态 | 根目录“Status”分区 | 进行中 → TaskBanner；结果 → ⋯ →“书库信息” |
| 漫画管理 | 行尾按钮、长按、侧滑各自一套 | 同一组动作（MoreMenu），资料编辑复用同一表单；点封面即阅读，菜单里不再放“阅读” |
| 书库管理（改名 / 信息 / 移除） | 首页行尾按钮 + 长按 | 书库内容页 ⋯ →“书库信息”；首页长按复用 |
| 服务器快捷入口 | 快捷区 + 菜单重复 | 只在“本服务器”快捷区 |
| 浏览服务器文件 | 多个入口 | 服务器详情一个“浏览文件”（从上次位置）；层级跳转用面包屑 |
| 离线书架 / 已保存文件夹 | 远程首页、服务器详情各自页面 | 同一页面两种范围（全部 / 当前服务器） |
| 远程漫画 | 一个菜单平铺 5–6 项 | 点封面阅读；菜单分本机副本 / 本地书库两组，写明去向 |
| 下载清理 | 离线书架按服务器清空（会清历史）+ 服务器管理 + 设置 | 服务器管理（本服务器）与设置 → 存储（全部），都保留历史 |
| 阅读器设置 | 顶栏 4 键 + 整屏控制面板 | 顶栏 [书签 · Aa · ⋯]；显示面板；更多菜单 |
| 页码与跳页 | 顶栏、底部、菜单 | 只在底部页码胶囊（受保护组件的现有行为） |

## 关键流程

| 场景 | 新步骤 | 变化 |
| --- | --- | --- |
| 第一次导入 | 书库 → 添加漫画 → 导入漫画 → 选去处 → 选择文件 / 选择文件夹 → 系统文件选择 → TaskBanner → 打开目标书库，结果条 | 方式按用途解释；去处记住上次；只读书库不可选并说明 |
| 使用已有文件夹 | 添加漫画 → 使用已有文件夹 → 系统授权 → 打开书库 → 需要时初始化（TaskBanner） | 权限失效用 Notice，与“空书库”分开 |
| 继续本地阅读 | 书库首页“继续阅读” → 漫画 → 退出回首页 | 少一层：不必先进书库（设置为“各书库内”时与现状相同） |
| 第一次远程阅读 | 远程 → 添加服务器 → 保存 → 服务器详情 → 浏览文件 → 漫画 | 只有一个“浏览文件”，首次从起始目录打开 |
| 准备离线 | 漫画 ⋯ → 保存离线副本 → 角标“下载中”→“已离线” → Toast“去离线书架” | 统一五态 |
| 远程导入 | 漫画或文件夹 ⋯ → 导入到书库… → 范围（含子文件夹，显示数量）与目标 → TaskBanner → 打开目标 | 开始前写数量与去向 |
| 整理多本 | 选择 → 勾选 → 底栏动作 → 完成 | 标题写数量；移出分组不删文件 |
| 清理空间 | 设置 → 存储 → 某一类 → 确认弹窗（删什么 / 留什么）→ 刷新占用 | 分三组，没有一键清理 |

## 删除、移除与清理（文案须表达的后果）

| 操作 | 影响 |
| --- | --- |
| 从标签 / 阅读列表移出，或删除分组 | 只删分组关系，漫画文件保留 |
| 移除关联文件夹书库 | 移除 App 内书库与整理记录，源文件夹保留 |
| 删除 App 内书库 | 删除书库及本机漫画文件 |
| 删除“已导入漫画” | 删除书库及其中文件；仍是默认导入去处，下次导入时重建为空书库（确认弹窗写明） |
| 删除本地漫画 | 删除记录与实际文件（关联文件夹中的文件也会被删除） |
| 移除已保存文件夹 | 只移除快捷入口 |
| 移除离线副本 / 清理远程下载 | 删除本机副本，服务器文件与阅读历史保留 |
| 删除 / 清除远程阅读历史 | 移除历史、进度与书签记录，下载文件保留 |
| 删除服务器 | 移除配置、凭据、相关下载、历史与快捷方式，服务器文件保留 |
| 修改服务器位置或账户 | 可能清理旧位置的历史、快捷方式和副本，保存前确认 |
| 清理临时数据 / 远程封面 | 只清可重建数据 |
| 清空“已导入漫画” | 删除默认导入书库中的文件，书库保留 |
