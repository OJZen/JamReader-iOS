# ScreenRemoteHome

Remote home (formerly Browse).

- Two top entry cards: Offline Shelf (all servers) and Saved Folders (all servers). These are different scopes of the same pages used by the matching server-detail entries.
- Server rows: name, address summary, protocol label. Do not show unverified online/offline status.
- iPad / inner-display sidebars are narrow, so server rows omit protocol labels and ⋯. Put protocol in the subtitle (“WebDAV · nas.local”) and actions in long press and left swipe. Names use the full row width, up to two lines.
- Saved Folders consistently uses a pin (`pin`), not a star; stars mean favorite comics in Library, a different meaning.
- Add/Edit Server: a protocol segmented control switches fields; errors retain input; keep only one footnote: “Servers connect when you open them after saving.”
