# ScreenRemoteHome

远程首页（原“浏览”）。

- 顶部两个入口卡：离线书架（全部服务器）、已保存文件夹（全部服务器）。与服务器详情里的同名入口是同一页面的不同范围。
- 服务器行：名称、地址摘要、协议标签。不显示无法确认的“在线/离线”状态。
- iPad / 内屏侧栏窄，服务器行不放协议标签和 ⋯：协议写进副标题（“WebDAV · nas.local”），操作在长按菜单与左滑里，名称占满整行、最多两行。
- 已保存文件夹的图标统一为图钉（`pin`），不再用星形——星形在书库里表示“收藏漫画”，两处含义不同。
- 添加/编辑服务器：协议分段切换字段；错误时保留输入；脚注只留一句“保存后进入服务器时才会连接”。
