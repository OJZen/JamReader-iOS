# ProtectedNavigation

**受保护组件，不在本次改版范围。** 分页阅读底部缩略图导航列表（`ReaderBottomBar` + `ReaderThumbnailScrubber`，含其页码胶囊与浮动预览）和竖向阅读右侧缩略图导航列表（`ReaderVerticalThumbnailRail`）原样沿用。

## 约束
- 位置、尺寸、间距、缩略图样式、圆角（13 / ≤8）、放大与抬升动效、显隐、触控、跳页行为全部不改。
- 本卡片仅按代码数值示意（compact：缩略图 40×58、条目 46×76、帧高 100；轨道容器 136pt、交互宽 68pt），不是新设计。
- 共享 token 改动（`Spacing`、`AppFont`、材质）不得通过引用间接改变它们：实现时这两个组件改为引用私有常量或冻结当前值。
- 周边工具（顶栏、显示面板、更多菜单）的出现与动画不得挤压或移动它们。

## iPhone Duo：只做环境适配
- 档位改为“iPad 或常规宽度窗口 → iPad 档，其余 → iPhone 档”，不再只看设备；iPad 上结果不变，Duo 内屏用 iPad 档、外屏用 iPhone 档。
- 容器在安全区内，避开侧边的状态栏与灵动岛；半折时限制在一个可用区域（底部列表：竖向折叠放后缘一侧；右侧轨道：横向折叠限制在下半区）。
- 档位由窗口决定，不随半折后变窄的容器变化；外观、动效、手势与跳页不变。对照 `ScreenDuoReader`。
