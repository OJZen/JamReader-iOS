# ScreenRemoteActions

远程漫画的三种意图与准备阅读。

- 点封面 = 阅读（必要时先下载）。“更多”不再重复“阅读”，只分两组：本机副本（保存、更新、移除、打开本机的较旧副本）/ 本地书库（导入到书库…），外加信息。不用一个含糊的下载图标表达全部。
- 导入 Sheet：来源路径、是否包含子文件夹（显示两种数量）、目标书库与文件夹、去向说明；按钮写数量。
- 准备阅读：封面停在开场动画的落点，超过约 1 秒才在封面上写明为何要下载（格式或服务器不支持边读边取）和进度；左上 × 是唯一的取消入口（取消下载并返回），不再另放“取消”按钮。失败时给重试 / 编辑服务器出口；黑底保留封面（打开时带来的预览，或磁盘上缓存的封面），没有缓存封面时显示警告图标；窗口太矮放不下封面和按钮时也只显示图标。
