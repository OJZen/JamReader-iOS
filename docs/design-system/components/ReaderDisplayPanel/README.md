# ReaderDisplayPanel

显示设置面板（`Aa`）：把原 `ReaderControlsSheet` 中的布局部分独立出来，所见即所得地调整。

## 结构
- iPhone：底部浮动面板（两侧留 12pt），画面仍可见；iPad：从 `Aa` 弹出 popover，最大宽 `size-overlay-max`。
- 阅读模式（左右翻页 / 竖向滚动）用图示卡片；其余用分段控件和开关。
- 只显示当前能生效的控件（完整对照见“阅读器”章节）：
  - 窄窗口分页：阅读模式、适应、页间距、旋转。
  - 宽窗口分页：再加 单页 / 双页；选双页后出现“双页排列”和“首页单独显示”。
  - 竖向：阅读模式、页间距。
  - PDF / EPUB 渲染页：只有旋转。
- 方向控件改叫“双页排列”：它只决定双页时左右两页的顺序，叫“方向”会让人以为能改翻页方向。
- 脚注只写一句作用范围。

## 保护
面板打开时，底部导航列表 / 右侧轨道不移动、不重排。

第 4 批实现说明（2026-10-30）：`ReaderDisplayPanel.swift`。紧凑宽度用系统 sheet（高度随内容、背后不变暗可操作，点 × 或下滑关闭），常规宽度用 popover；两者都用实色 `surface` 底。单页分页不显示“页间距”（单页时不起作用）。“首页单独显示”是原“页面配对”同一偏好的开关形式；适应方式保留“原始大小”。
