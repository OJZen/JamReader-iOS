# ScreenSettings

设置：通用 / 阅读 / 书库 / 存储（`SettingsHomePane`），iPhone 列表进入，iPad 侧栏常驻。

- 首页每个分类的副标题显示当前关键值，减少进入次数。
- 书库：继续阅读显示在（书库首页 / 各书库内；**功能变化**，默认书库首页）、最近加入时间范围、远程导入默认范围。
- 去掉“书库数量”只读行：书库首页已经列出全部书库，设置里重复显示没有决策价值。（改版变化）
- 存储：一条分段占用条（不借用状态色）；分组 = 远程下载（上限、阅读时下载完整副本、已下载 + 清理）/ 可重建的数据（临时数据、远程封面）/ 你的文件（“已导入漫画”+ 清空）。每类行尾是同样的按钮，后果统一写在 ConfirmDialog，页面上不再逐条写脚注；没有“一键清理”。
