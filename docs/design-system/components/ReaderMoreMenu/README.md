# ReaderMoreMenu

阅读器“更多”菜单：替代现有一整屏的 `ReaderControlsSheet`，按“页面 / 这本漫画”分组。

- **页面**：缩略图总览（复用 `ReaderThumbnailBrowserSheet`）、书签（子菜单：每个书签一行可跳转，末尾“删除书签”）、存到相册（处理授权与失败）。
- **跳到页码不进菜单**：点底部页码胶囊（竖向为紧凑页码入口）打开现有 `ReaderPageJumpOverlay`，这是它唯一的入口，与受保护组件的现有行为一致。
- **这本漫画**（仅本地）：收藏、标为已读（会把阅读位置移到末页 / 首页，执行后 Toast 说明）、标签与列表、评分（子菜单）、编辑资料、信息。远程只保留信息。
- 分组标题：“页面”正常显示；“这本漫画”以一排快捷动作开头，系统菜单不画它的标题，只留分隔线。
- 不支持的能力直接不出现（PDF/EPUB 没有书签与相册时隐藏）。
