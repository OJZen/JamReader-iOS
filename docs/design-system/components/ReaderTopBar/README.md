# ReaderTopBar

阅读器顶栏（重设计，`ReaderTopBar`）。叠加在画面上，显示/隐藏不改变漫画尺寸。

## 结构
- 左：返回（44pt 圆形 `reader-chrome`）。
- 中：书名 `reader-title`，纯文字，不做成胶囊——胶囊看起来像按钮，但它不可点。顶部一层随工具一起淡入淡出的渐变遮罩（`jr-rscrim`）保证书名在浅色页面上可读，遮罩不占布局、不改画面。
- **不显示页码**：页码与百分比已经在受保护的底部页码胶囊（竖向为紧凑页码入口）里，顶栏不重复。
- 右：一个三键胶囊——书签（当页切换，已加时为果酱色实心）、`Aa` 显示设置、`…` 更多。原来的“浏览页面”“存到相册”两个独立按钮收入“更多”，顶栏从 4 键减为 3 键。
- 本地书签已满 3 个时，点书签弹出系统 Alert：“每本最多 3 个书签”，并给“管理书签”入口；不静默失败。
- 跨本导航胶囊（现 `ReaderContextNavigator`）保持位置与行为，仅换为同一材质。

## 不可改
不改变点按区域、显示时机与动画曲线（`AppAnimation.chromeToggle`）。工具避开安全区。
