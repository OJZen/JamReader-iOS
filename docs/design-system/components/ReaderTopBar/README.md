# ReaderTopBar

阅读器顶栏（`ReaderTopBar`）。叠加在画面上，显示/隐藏不改变漫画尺寸。

## 结构
- 左：返回（44pt 圆形 `reader-chrome`）。
- 中：书名 `reader-title`，纯文字，不做成胶囊——胶囊看起来像按钮，但它不可点。顶部一层随工具一起淡入淡出的渐变遮罩（`jr-rscrim`）保证书名在浅色页面上可读，遮罩不占布局、不改画面。
- **不显示页码**：页码与百分比已经在受保护的底部页码胶囊（竖向为紧凑页码入口）里，顶栏不重复。
- 右：一个三键胶囊——书签（当页切换，已加时为果酱色实心）、`Aa` 显示设置（再点一次关闭面板）、`…` 更多。原来的“浏览页面”“存到相册”两个独立按钮收入“更多”，顶栏从 4 键减为 3 键。
- 满额书签使用一步替换 Alert，行为与数量边界见 [阅读器需求](../../../design-requirements.md#5-漫画阅读器保护范围与可改部分)。
- `Aa` 图标固定用拉丁字形，避免 SF Symbols 在中文 / 日文下换成本地字形。

## 不可改
不改变点按区域、显示时机与动画曲线（`AppAnimation.chromeToggle`）。工具避开安全区。

静态稿的跨本导航胶囊没有页面调用，见 [实现取舍](../../05-batches.md#阅读器)。
