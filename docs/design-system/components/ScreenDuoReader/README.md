# ScreenDuoReader

iPhone Duo 上的阅读器。完整规则见“iPhone Duo”章节（仓库中为 `06-iphone-duo.md`）与“阅读器”章节。设备框按比例示意。

- 单页 / 双页按用户偏好，内屏横放不自动切双页；外屏是紧凑宽度，没有双页，临时显示单页但**不改写**偏好，回到内屏恢复。
- 双页：跨页中心对准折痕（division 区域中线，用包含未启用区域的查询），不用安全区中心——侧边状态栏让安全区左右不对称。半折时两页分居折叠区两侧，各自适应一侧；平放时恢复相接。
- 单页在内屏横放时居中跨过折痕：这是内容，允许；点按区域不变。
- 顶栏保持水平（返回 · 书名 · 三键），整体在安全区内，左右用系统容器边距（靠侧边列那一侧不再加边距）；半折时书名在折痕前截断，三键在后缘一侧。
- `Aa`：紧凑宽度用底部浮动面板，常规宽度用 popover；按尺寸类别判断，不按设备。关闭方式见 `ReaderDisplayPanel`。
- 两个受保护导航列表**只做环境适配**：外观、动效、手势、跳页不变；档位按窗口（iPad，或窗口的宽、高尺寸类别都为常规用 iPad 档，其余用 iPhone 档）；容器在安全区内，半折时限制在一个可用区域（竖折：后缘一侧；横折：下半区）。容器变窄只改变能看到的缩略图数量，不改尺寸。
- 不做桌面姿势专用模式。
