# ContinueReading

继续阅读：首页与书库根目录的第一块内容，让“接着看”成为最短路径。

## 结构
- 第一本用横向“主卡”（84pt 封面 + 书名 + 进度 + “继续”按钮），其余用横向卡带（`size-shelf-cover` 112pt，iPad 140pt）。
- 每张卡显示进度百分比和来源书库名（仅首页汇总时显示来源；书库内不显示）。
- 分区标题 `title2`，右侧“全部”进入“继续阅读”页（见下方范围）。

## 范围（同一时刻只出现在一处）
由“设置 → 书库 → 继续阅读显示在”决定，避免只有一个书库时首页和书库里出现两条一模一样的卡带：
- **书库首页**（默认）：汇总所有本地书库，卡片注明来源书库；书库根目录不再放卡带，单个书库内用筛选“阅读中”找回同样的内容。属于功能变化。
- **各书库内**：与现状一致，每个书库根目录显示本书库的继续阅读，首页不显示。
- **服务器详情**：远程阅读历史使用同一组件，来源为该服务器，不受此设置影响。
- 书库内的“全部”复用集合页；首页汇总的“全部”是按书库分组的只读页面，只提供阅读和“在书库中显示”。
  - 原因：集合页的搜索与批量动作只对单个书库成立，汇总页用同一套封面卡、网格与分组标题搭建（见 05-batches 第 5 批实施说明）。

## Do / Don't
- Do：点击封面直接进入阅读器，回到原位置。
- Don't：把远程与本地进度合并成一条，也不要宣称导入后进度同步。
