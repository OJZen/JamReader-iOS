# TaskBanner

长任务浮条：导入、远程导入、批量离线保存的唯一进度入口（复用现有 `LibraryImportProgressView` 位置，`safeAreaInset(.bottom)`）。

## 规则
- 悬浮在标签栏上方，材质 `glass`，圆角 `radius-xl`；不遮挡列表其它控件。
- 必有：做什么、到哪里（目标书库/文件夹）、计数、进度、取消（×）。
- 结束后变为结果条：完全成功 → 自动 4 秒后消失并提供“打开”；部分成功/失败 → 常驻直到用户查看，列出 新增 / 已存在 / 失败 数量。
- 不新增任务中心页面；远程导入在 App 内切换页面时保留此条。
- 不承诺退出 App 后续传。

第 2 批能力边界（2026-10-28 核实）：导入服务的导入数包含复用的文件，拿不到单独的“已存在”数量，结果条写“已导入 / 不支持 / 失败”。扫描没有取消能力，进行中不显示 ×；导入可以取消。从书库首页开始的导入结束后打开目标书库，结果条出现在那一页。ComicInfo 资料导入仍用原来的结果提示。
