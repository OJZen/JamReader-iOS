# ScreenDuoLibrary

iPhone Duo 上的书库（远程、设置的外壳同理）。完整规则见“iPhone Duo”章节（仓库中为 `06-iphone-duo.md`）。设备框按比例示意，不是实际点数。

- 外屏 = 紧凑宽度 = 现有 iPhone 布局；内屏 = 常规宽度 = 现有 iPad 布局（侧栏常驻）。层级不变，内屏只多显示一层侧栏。
- 判断依据是窗口的尺寸类别与容器宽度，不是设备类型：split view 始终创建，由系统在外屏折成单栏、在内屏展开。
- 侧边控件由系统摆放（外屏、内屏横放），内屏竖放保留水平栏。不覆盖默认放置，不自绘侧边栏。
- 每个工具栏项同时给标题和 SF Symbol；“选择”在侧边列显示为 `checkmark.circle`，标题仍是“选择”。
- 半折时：split 两栏由系统调成对称；可交互元素不放在折叠区；滚动内容可以跨过。
- 侧栏宽度不写死 320，让系统能在半折时调成对称。
- 页面左右边距用系统的容器边距（`contentMargins(for: .container)` / UIKit 布局边距），不写死 16：靠近侧边控件那一侧边距约为 0，内容直接贴到控件列；分屏在左时控件在前缘，边距随之对调。
- 只有系统管理的栏会进侧边列：选择模式的动作用系统底部工具栏项；“完成”钉在最上；“更多”并入系统溢出菜单；“全选”文字按钮设为只水平，留在导航栏。
- 不开启标签栏的侧栏放置，避免与分区自己的侧栏重复。
- 开合时保留当前分区、导航层级、滚动位置与选择状态。
