# ComicCover

封面条目：漫画在网格中的唯一表达，封面占主体，书名两行，副标题一行说明当前最重要的一个状态。

不再使用“未读圆点”：书库里大多数漫画默认就是未读，满屏圆点只会成为噪音；需要找未读时用 FilterChips 的“未读”。

## 何时使用
- 书库内容、集合、远程目录、离线书架的网格模式；iPhone 默认 3 列（`size-grid-min-compact`），iPad 按 `size-grid-min`–`size-grid-max` 自适应。
- 点击封面 = 直接打开阅读器（hero 过渡，见 `00-foundations` 的动效）。没有阅读前的详情页。

## 消费方提供
- 封面图（本地 `LocalCoverThumbnailView` / 远程 `RemoteComicThumbnailView`），缺失时显示 `surface-2` 底 + `book` 图标，不显示文件扩展名图片。
- `title`（2 行截断）、一个副标题状态、可选进度（0–1）、角标状态、选择态。

## 状态规则
| 优先级 | 状态 | 表达 |
| --- | --- | --- |
| 1 | 选择模式 | 右下圆形勾选，未选中不变暗；不可选（如远程不支持的操作）整卡 55% 透明 |
| 2 | 失败 / 下载中 | 右上角标（`danger` 警告 / 进度环）+ 副标题文字 |
| 3 | 远程副本 | 已离线 `offline` 实心下载图标；较旧副本 `warning` 时钟 |
| 4 | 阅读进度 | 底部 3px `jam` 进度条 + “读到 42%” |
| 5 | 已读 / 未读 | 只写在副标题里（“已读”带勾，“未读”纯文字），封面上不加圆点 |
| — | 收藏 | `favorite` 星角标，只在角标位空闲时出现 |

角标位（右上）一次最多一个；底部进度条与角标位置不同，可以同时出现。

## Do / Don't
- Do：副标题写人话（“读到 42%”“已离线”），颜色只是辅助。
- Don't：在封面上叠多个徽标、文件格式、大小；这些放到“更多 → 信息”。
- Don't：把“已离线”画成“已导入书库”，二者是不同概念。
