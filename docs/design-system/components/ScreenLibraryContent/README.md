# ScreenLibraryContent

书库内容页：文件夹逐级浏览 + 漫画网格（iPhone 默认 3 列网格，可切列表——**改版变化**）。

## 结构（自上而下，仅根目录有集合）
搜索（本书库，最多 40+40 条）→ 集合入口 2×2 → 文件夹 → 漫画。
- 漫画分区标题右侧是排序（名称 / 加入时间 / 最近打开…），下面一行快捷筛选（全部 / 未读 / 阅读中 / 已读 / 有书签）；筛选只作用于当前文件夹的漫画，文件夹照常显示。筛选“阅读中”就是本书库的继续阅读。
- 继续阅读默认在书库首页汇总；设置为“各书库内”时，卡带出现在集合入口与文件夹之间。

## 工具栏（根目录与子文件夹相同）
- “选择” · ⋯。⋯ 依次为：导入到这里… / 网格 · 列表 / 导入漫画资料… / 刷新与扫描 / 书库信息。
- 只读的关联文件夹里“导入到这里”置灰，并在菜单副标题写“文件夹只读”。空文件夹的空状态按钮也是“导入到这里”。
- “最近加入时限”从此页菜单移除，只在设置和“最近加入”页出现。
- 扫描进度、维护记录不再占用“状态”分区：进行中用 TaskBanner，结果写在“书库信息”。
- “书库信息”里集中：改名、存放位置、只读 / 授权状态与重新授权、上次扫描结果、移除或删除书库。

第 2 批实现说明（2026-10-28）：现有书库服务没有原地重新授权，“书库信息”只说明访问失败与记录保留，不放无效按钮。继续阅读暂用书库内的原组件，放在集合入口与文件夹之间；首页汇总与集合页快捷筛选在第 5 批。“导入到这里…”是子菜单（选择文件… / 选择文件夹…）；整个书库的刷新与资料导入在子文件夹里同样可用。

## 导入漫画资料（ComicInfo）
统一为“导入漫画资料…”一个入口：先选范围（所选漫画 / 当前列表 / 当前文件夹及子文件夹 / 整个书库），再选“只补空白 / 覆盖已有字段”。
