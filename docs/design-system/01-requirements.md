# 需求整理

依据：`docs/design-requirements.md`、`docs/ui-guidelines.md` 与当前代码（`JamReader/Features`、`SharedUI`、`App`）。本章只整理**现有功能**与**本次确认的改版决定**；新增功能单独标注。

## 目标

让用户容易**找到漫画、开始阅读、管理文件**，同时完整保留已经调好的阅读手感。

| 用户想做什么 | 产品要帮他完成什么 |
| --- | --- |
| 日常阅读 | 一打开就能接着看，退出后记住位置 |
| 整理收藏 | 导入、按文件夹 / 标签 / 阅读列表找书、改资料 |
| 读 NAS 上的漫画 | 连上 SMB / WebDAV，浏览、直接读，或保存离线副本 |
| 管理空间 | 分清“我的文件”和“可重建缓存”，再决定清理什么 |

## 现状中“乱”的地方（来自代码）

1. **首页不回答“接着看什么”。** 书库首页只是书库列表；“继续阅读”埋在每个书库的根目录里。
2. **添加入口用存储术语。** [+] 菜单并列四项：New Library / Add Library Folder / Import Comic Files / Import Comic Folder，新用户要先理解“托管”和“关联”。
3. **书库内容页菜单堆叠。** 工具栏有 View（最近加入时限、排序、显示）与 Library（Import ComicInfo、Import Comic Files、Refresh & Scan → Refresh Library / Refresh Current Folder / Import Library ComicInfo / Import Current Folder ComicInfo）两组，ComicInfo 入口在“导入”和“刷新与扫描”两处重复。
4. **维护信息占内容位。** 根目录有“Status”分区（维护记录、扫描进度、只读提示），和漫画同等视觉权重。
5. **层级导航重复。** 页面里有“Up / Library”按钮，与系统返回键重复。
6. **远程入口重复且命名不一。** 服务器详情的 Shortcuts 与菜单都有 Saved Folders / Offline Shelf；同一个东西有 “Downloaded Comics”“Offline Shelf”“Downloads” 多种叫法。
7. **清理后果不一致。** 离线书架里按服务器 “Clear Downloads” 会同时清掉阅读历史与进度，而服务器管理和设置里的清理会保留历史。
8. **远程漫画意图混在一起。** Save for Offline / Refresh / Update / Open Older Downloaded Copy / Import to Library 平铺在同一菜单。
9. **阅读器工具分散。** 顶栏 4 个按钮，“更多”打开一整屏控制面板（文件信息、页面、阅读状态、书库操作、显示、旋转、书签共 7 个分区）。
10. **视觉没有体系。** `AccentColor` 为空（等于系统蓝）；状态色写成 `.green.opacity(0.8)` 等零散值；`StatusBadge` 只有颜色与文字；“浏览”标签名与“浏览书库”混淆。

## 本次确认的改版决定

| 决定 | 说明 | 类型 |
| --- | --- | --- |
| 品牌主色：果酱（深红偏紫） | `jam` #9B1E56 / #C23A76（填充与标记），`accent` #9B1E56 / #E886B2（可点文字），`jam-deep` #5C1233（品牌色块），搭配蜂蜜金 `favorite`。由第一轮的珊瑚色改为果酱色，呼应 JamReader 的名字 | 视觉 |
| iPhone 书库默认封面网格（3 列），可切列表 | `size-grid-min-compact` 100pt | 改版变化 |
| 书库首页汇总“继续阅读”（仅本地书库） | 设置 → 书库 → “继续阅读显示在：书库首页 / 各书库内”，默认书库首页；同一时刻只在一处出现 | **功能变化 · 已确认** |
| 集合页接入快捷筛选 | 收藏 / 最近加入 / 标签 / 阅读列表：全部、未读、阅读中、已读、有书签 | **功能变化 · 已确认** |
| “浏览”改名“远程” | 图标 `server.rack` | 文案 |
| “添加漫画”改为按用途的 Sheet | 导入漫画 / 使用已有文件夹 / 新建空书库 | 改版变化 |
| 阅读器顶栏 3 键 + 显示面板 + 更多菜单 | 替代整屏控制面板；底部 / 右侧导航列表不动 | 改版变化 |
| 适配 iPhone Duo | 外屏 = iPhone 布局，内屏 = iPad 布局，按窗口宽度切换；内屏横放沿用单双页偏好；半折只做系统要求的避让；受保护导航列表只做环境适配（见 `06-iphone-duo.md`） | 适配 |
| 移除离线书架里的整服务器“清空下载” | 统一到服务器管理与设置 → 存储（保留历史） | 行为修正 |

## 二次审查后的调整

| 问题 | 类型 | 调整 |
| --- | --- | --- |
| 只有一个书库时，首页与书库根目录会出现两条一样的“继续阅读” | 重复入口 | 开关改为二选一的“继续阅读显示在”；书库内用筛选“阅读中”找回本书库内容 |
| “添加漫画”第一张卡内有“选择文件 / 选择文件夹”，下一步又出现“选择文件” | 反直觉 | 三张卡交互一致（整卡进入下一步）；下一步先选去处，再选文件或文件夹，且记住上次去处 |
| 书库根目录用 ⋯ 导入，子文件夹用工具栏按钮导入 | 不一致 | 两处工具栏都是“选择” · ⋯，“导入到这里”固定在 ⋯ 第一项 |
| 排序、网格切换散落在菜单与列表头 | 不一致 | 排序固定在“漫画”分区标题右侧，显示方式在 ⋯ |
| 封面“未读圆点” + 副标题“未读”重复，且大多数漫画默认未读，满屏圆点 | 冗余 | 去掉圆点，副标题写状态；找未读用筛选 |
| 顶栏副标题“第 78 / 186 页”与受保护的底部页码胶囊重复；书名胶囊看起来像按钮却不可点 | 冗余 / 反直觉 | 顶栏只放书名（纯文字 + 渐变遮罩），页码只在底部 |
| 阅读器“更多”里的“跳到页码”与点底部页码胶囊重复 | 重复入口 | 菜单移除，保留页码胶囊这一现有入口 |
| 显示面板在 iPhone 窄窗口也显示“方向”，但它只影响双页排列 | 反直觉 | 改名“双页排列”，只在选双页时出现 |
| 系统菜单里放可点的星星行（实现不了） | 疏漏 | 评分改为子菜单 |
| 远程漫画菜单第一项“阅读”与点封面重复 | 重复入口 | 删除；菜单只放本机副本与导入书库 |
| 服务器详情“继续浏览”“从根目录浏览”两个大按钮 | 冗余 | 一个“浏览文件”（从上次位置打开），回根目录用面包屑 |
| 已保存文件夹用星形，与“收藏漫画”同形不同义 | 反直觉 | 改为图钉 |
| 准备阅读页左上 × 与底部“取消”重复 | 重复入口 | 只保留 × |
| 离线书架筛选“最新 / 较旧”两项，用户只关心要不要更新 | 冗余 | 合并为“需要更新 N”；联网时较旧副本行内直接“更新”，断网时不显示这个必然失败的按钮 |
| 已保存文件夹、标签页的“左滑可以……”脚注 | 冗余文本 | 改为导航栏“编辑”按钮，后果写进确认弹窗 |
| 标签页里混放阅读列表 | 不一致 | 标签、阅读列表各自一页，结构相同 |
| 存储页清理控件有红字行、有按钮，存储条借用警告色 | 不一致 | 每类一行“大小 + 清理”，后果在确认弹窗；存储条用中性 `chart-*` 色 |
| 设置里“书库数量”只读行 | 冗余 | 删除（首页已列出全部书库） |
| iPad 侧栏已有继续阅读与集合，内容区又放卡带；自绘了底部分段标签 | 重复入口 / 疏漏 | 内容区从文件夹开始；分区切换用系统标签栏 |
| 浅色背景上 `surface` 白卡与白底融在一起 | 疏漏 | 书库首页、远程首页、服务器详情、设置用 `bg-grouped`；内容网格页的集合卡用 `surface-2` |
| 浅色 `favorite` 只有 2:1 | 对比度 | 改为 #B97F00（3.4:1） |

## 不在本次范围

账号与云同步、内容商店、远程与本地合并的继续阅读、全局 / 远程搜索、进度同步、扩大本地书签数量（仍为每本 3 个）、重做阅读手势、源文件改名移动、远程文件删除、App 退出后的下载续传、“测试连接”按钮。设计稿不画这些。

## 必须画出的状态（检查表）

- 第一次使用 / 没有内容；内容很多、长书名、缺封面
- 加载或准备阅读（可取消）
- 搜索无结果（写出范围，说明漫画没被删除）
- 文件夹权限失效 vs 只读
- 网络 / 登录 / 路径错误（保留位置与输入）
- 部分成功 / 取消（新增、已存在、失败分别计数）
- 空间不足 / 保存失败
- 修改未保存
- 不支持的格式或能力（PDF / EPUB 没有布局与书签控件时不显示）
- 任务或阅读占用导致暂时不能清理
