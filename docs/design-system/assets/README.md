# Design Illustrations

This directory keeps 3 app-icon candidates. See [PROMPTS.md](PROMPTS.md) for their generation prompts.

- Images are for design review only, not app assets. Do not copy them directly into `JamReader/`, which Xcode includes automatically.
- `app-icon/concept-1.png`, `concept-2.png`, and `concept-3.png` are all 1024×1024. No icon has been selected; the app's `AppIcon.appiconset` has only light, dark, and tinted slots, with no image files.
- This directory has no final icon variants, sample covers, or comic pages. Page mockups continue to use placeholders; do not list ungenerated files as implementation tasks.
- Candidate generation requires original graphics, without characters or logos from existing works.
