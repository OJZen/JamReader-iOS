# 设计示意图片

本目录保留 3 张 App 图标候选稿。候选生成提示词见 [PROMPTS.md](PROMPTS.md)。

- 图片只用于设计评审，不属于 App 资源；不要直接复制进 `JamReader/`，该目录会被 Xcode 自动收录。
- `app-icon/concept-1.png`、`concept-2.png`、`concept-3.png` 均为 1024×1024。图标尚未选定；App 的 `AppIcon.appiconset` 只有浅色、深色、tinted 槽位，没有图片文件。
- 本目录没有正式图标变体、示意封面或漫画页；页面稿继续使用占位图，不把未生成文件列成实施任务。
- 候选生成要求使用原创图形，不采用现有作品的角色或标志。
